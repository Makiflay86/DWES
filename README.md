# Ejercicios Prácticos de Desarrollo Web: Bootstrap y PHP

## Descripción General

Este repositorio es una colección de ejercicios de desarrollo web enfocados en afianzar el manejo de dos tecnologías clave:

1.  **Framework Bootstrap** (HTML/CSS): Para el diseño y la maquetación **frontend** (interfaz de usuario).
2.  **Lenguaje PHP**: Para la lógica **backend** y la gestión de datos, incluyendo la práctica con relaciones básicas.

---

## Estructura del Repositorio

| Carpeta | Contenido Principal | Propósito |
| :--- | :--- | :--- |
| **`html/`** | Archivos `.html`, `.css`, y `.js` | Contiene ejercicios que demuestran el uso del **sistema de *grid*** y los **componentes** de Bootstrap para crear páginas responsivas. |
| **`php/`** | Archivos `.php` | Colección de **4 relaciones de ejercicios** centrados en la lógica *backend* y el manejo de **relaciones** (ej. tablas, datos enlazados) para mejorar el dominio de PHP. |

---

## Uso y Requisitos

Para poder visualizar y ejecutar todos los ejercicios del repositorio, se deben cumplir los siguientes requisitos:

### 1. Requisitos de Bootstrap (Frontend)

* **Necesitas:** Un **navegador web** moderno (Chrome, Firefox, Edge, etc.).
* **Para usarlo:** Simplemente haz doble clic en cualquier archivo `.html` dentro de la carpeta `html/` para verlo.

### 2. Requisitos de PHP (Backend)

* **Necesitas:** Un **servidor web local** que soporte PHP (se recomienda **XAMPP**, **WAMP** o **Laragon**).
* **Para usarlo:**
    1.  Asegúrate de que tu servidor local (Apache y PHP) esté en funcionamiento.
    2.  Copia la carpeta **`php/`** y pégala en el directorio raíz de tu servidor local (`htdocs` en XAMPP, `www` en WAMP, etc.).
    3.  Accede a los ejercicios a través de la URL de tu servidor local (ej. `http://localhost/php/1relacion1.php`).
