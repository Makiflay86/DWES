# Relación 1: Fundamentos de PHP

Este módulo de ejercicios está totalmente dedicado a la práctica de los **fundamentos esenciales del lenguaje PHP**. Los archivos contenidos aquí están diseñados para reforzar el manejo de **variables y constantes**, la correcta **salida básica** de datos en la web (impresión en pantalla), y el uso de **sentencias de control de flujo** fundamentales (estructuras condicionales y ciclos). Al completar esta sección, se asegura una base sólida en el control de flujo y la sintaxis antes de avanzar a temas más complejos como las funciones y las estructuras de datos.

---

## Cómo Acceder a los Ejercicios

Para ver la lista de ejercicios de esta relación:

1.  Asegúrate de que tu servidor local (XAMPP/WAMP/etc.) esté en funcionamiento.
2.  Accede al índice de esta carpeta a través de tu navegador:

    ```
    http://localhost/php/relacion1/index.html
    ```
    (O navegando directamente desde el enlace correspondiente en el `super-index.html` principal).
