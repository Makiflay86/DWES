# Relación 4: Persistencia de Datos y POO

Este módulo final consolida las habilidades de desarrollo introduciendo conceptos avanzados esenciales para construir aplicaciones web funcionales. Los ejercicios se enfocan en la **persistencia de datos** y el **diseño de software**. Esto incluye el manejo del estado del usuario mediante **Sessions y Cookies** de PHP, la serialización y el intercambio de datos utilizando el formato **JSON**, y la implementación de la **Programación Orientada a Objetos (POO)**. La práctica con POO (Clases, Objetos, Herencia) y la manipulación de formatos de datos y estado prepara los ejercicios para la creación de lógica *backend* estructurada y escalable.

---

## Cómo Acceder a los Ejercicios

Para ver la lista de ejercicios de esta relación:

1.  Asegúrate de que tu servidor local (XAMPP/WAMP/etc.) esté en funcionamiento.
2.  Accede al índice de esta carpeta a través de tu navegador:

    ```
    http://localhost/php/relacion4/index.html
    ```
    (O navegando directamente desde el enlace correspondiente en el `super-index.html` principal).
