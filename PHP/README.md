# Ejercicios de Manejo y Relaciones con PHP

Este directorio contiene una colección de **cuatro bloques de ejercicios prácticos** (`relacion1` a `relacion4`) diseñados para afianzar el conocimiento y el manejo del lenguaje **PHP** en el contexto del desarrollo *backend* y la gestión de datos, centrándose en la práctica de la lógica del servidor, el flujo de control, y la implementación de diferentes relaciones y operaciones de datos. El archivo **`super-index.html`** actúa como un *dashboard* central, proporcionando un acceso organizado y rápido a la página de índice de cada uno de los módulos de ejercicios.

---

## Estructura del Directorio

| Archivo/Carpeta | Contenido Principal | Propósito |
| :--- | :--- | :--- |
| **`super-index.html`** | Archivo HTML | **Índice central** y punto de entrada para navegar a cada bloque de ejercicios. |
| **`relacion1/`** | Archivos PHP | Bloque 1: Enfocado en **[Variables, constantes, salida básica y sentencias de contro]**. |
| **`relacion2/`** | Archivos PHP | Bloque 2: Enfocado en **[Entrada con formulario, estilo Bootstrap y validación JS]**. |
| **`relacion3/`** | Archivos PHP | Bloque 3: Enfocado en **[Funciones, recursividad y uso avanzado de Arrays]**. |
| **`relacion4/`** | Archivos PHP | Bloque 4: Enfocado en **[Sessions, Cookies, JSON y POO, ej: Manejo de Sesiones]**. |

---

## Requisitos y Uso

Para ejecutar y probar los ejercicios de PHP:

1.  **Requisito:** Necesitas un **servidor web local** que soporte PHP (ej. XAMPP, WAMP, Laragon).
2.  **Instalación:** Coloca esta carpeta (`php`) dentro del directorio raíz de tu servidor (típicamente `htdocs` o `www`).
3.  **Acceso:** Abre tu navegador y accede al índice principal a través de la URL de tu servidor:

    ```
    http://localhost/php/super-index.html
    ```
