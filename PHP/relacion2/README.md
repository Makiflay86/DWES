# Relación 2: Formularios, Estilo y Validación

Este conjunto de ejercicios se centra en la creación de interfaces de **entrada de datos** robustas y con un diseño profesional, combinando tecnologías de *frontend* y *backend*. El módulo practica la implementación de **formularios** (`<form>`) para la captura de información del usuario y utiliza las clases de **Bootstrap** para aplicar un **estilo responsivo** y moderno a estos formularios. Crucialmente, estos ejercicios también abordan la **validación de datos** en el lado del cliente (utilizando **JavaScript**), garantizando que los datos ingresados sean correctos antes de ser enviados al servidor para su posterior procesamiento con PHP.

---

## Cómo Acceder a los Ejercicios

Para ver la lista de ejercicios de esta relación:

1.  Asegúrate de que tu servidor local (XAMPP/WAMP/etc.) esté en funcionamiento.
2.  Accede al índice de esta carpeta a través de tu navegador:

    ```
    http://localhost/php/relacion2/index.html 
    ```
    (O navegando directamente desde el enlace correspondiente en el `super-index.html` principal).
