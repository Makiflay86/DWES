# Relación 3: Funciones Avanzadas y Arrays Estructurados

Este módulo de ejercicios está diseñado para profundizar en la **arquitectura lógica del código PHP**, centrándose en tres pilares fundamentales para el desarrollo avanzado. El contenido se enfoca en la creación y el manejo de **Funciones** personalizadas, la implementación de la **Recursividad** para resolver problemas que requieren auto-llamadas (como el manejo de estructuras jerárquicas o cálculos complejos), y el **uso avanzado de Arrays**. Estos ejercicios exploran cómo manipular *arrays* de manera eficiente, incluyendo *arrays* asociativos y multidimensionales, consolidando así las habilidades para procesar y estructurar datos complejos en PHP.

---

## Cómo Acceder a los Ejercicios

Para ver la lista de ejercicios de esta relación:

1.  Asegúrate de que tu servidor local (XAMPP/WAMP/etc.) esté en funcionamiento.
2.  Accede al índice de esta carpeta a través de tu navegador:

    ```
    http://localhost/php-exercises/relacion3/index.html
    ```
    (O navegando directamente desde el enlace correspondiente en el `super-index.html` principal).
