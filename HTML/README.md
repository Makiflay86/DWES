# prueba-bootstrap.html: Página Turística de Málaga

Este ejercicio es una plantilla de página web simple y **completamente responsiva** desarrollada con **HTML5** y **Bootstrap 5.3.x**, cuyo objetivo es practicar la implementación de componentes de diseño web moderno, enfocándose en la información turística de Málaga.

## Componentes Clave

* **Diseño:** Uso intensivo del **Grid System** para asegurar la adaptabilidad (*responsive*).
* **Elementos Interactivos:** Implementación de **Navbar** colapsable y **Carousel** dinámico.
* **Estructura:** Uso de **Cards** (sección "Comer") y contenedores **Ratio** para hacer los *iframes* de videos y mapas completamente responsivos.
* **Estilo:** Utilización de clases de utilidades de Bootstrap (ej. `bg-info`, `text-center`, `rounded-circle`) y **Bootstrap Icons** en el *footer*.

## Cómo Visualizar

Solo tienes que abrir el archivo `prueba-bootstrap.html` directamente en cualquier navegador web moderno.
